Projects

Things I've Built

Practical projects where I learned by building, testing and debugging real hardware systems.

PROJECT 01

ESP8266 Two-Board Calculator

A two-ESP8266 calculator system using a 4×3 keypad and 16×2 LCD. One NodeMCU receives keypad input and communicates the data to another NodeMCU, which displays the result.

ESP8266 NodeMCU Keypad LCD Serial
PROJECT 02

ESP-NOW Wireless LED Remote

A wireless remote-control system using two ESP8266 boards. A button press on the transmitter sends a command through ESP-NOW to the receiver, which toggles an LED.

ESP8266 ESP-NOW Wireless GPIO Button
PROJECT 03

Wi-Fi Smart LED Dashboard

A web-based IoT dashboard running directly on an ESP8266. A phone or computer can connect to the device and control an LED through a browser interface. Features include ON/OFF control, blinking and adjustable blink speed.

ESP8266 Wi-Fi Web Server HTML IoT
